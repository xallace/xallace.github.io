The rules in short

Full text in DESIGN.md. A new app starts from the template and has to pass the check before it is pushed.

  • Dark only. No light mode, no theme toggle; color-scheme: dark.
  • Head: /fonts/xallace-type.css, then /design/xallace-ui.css, then the app's style.css; /fonts/xallace-type.js deferred before </body>.
  • One accent per app from vermilion, slate, emerald, cyan and ochre. No other colours in the UI.
  • Five type roles; VT323 only up to 0.70rem and never in canvas or SVG.
  • Drawing left, controls right; stacked below 1060 px; no horizontal scroll at 390 px.
  • Canvas and on-screen SVG take their colours from the tokens. SVG/DXF/PDF exports keep light print colours.
  • three.js: no outputEncoding/sRGBEncoding, dimmed lights.
  • UI in English. A standard claim not checked against the source gets not verified.
  • Model in its own file with node tests/verify.mjs.
  • Changes to the design only with Walter's OK, with a new version and changelog entry.
Check an app: node design/check.mjs ../my-app --browser (run in the xallace.github.io clone).
