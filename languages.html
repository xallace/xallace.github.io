Schritt-für-Schritt Leitfaden

Wie du eigene bilinguale Sprachwelten mit KI erstellst

Die exakte Methodik, System-Prompts und Skripte, um aus jedem Thema maßgeschneiderte Sprachlerntexte zu generieren.

SCHRITT 1 · DAS DIDAKTISCHE PRINZIP

Warum Satz-für-Satz Parallellesen so überlegen ist

Traditionelle Sprachkurse trennen Vokabellisten von der Grammatik. Beim interlinearen Parallellesen wendest du das Prinzip des Comprehensible Inputs an: Dein Gehirn erkennt Satzmuster, Kasusendungen und Zeitformen unbewusst, weil die muttersprachliche Entsprechung unmittelbar im Blickfeld liegt. Kein zeitraubendes Nachschlagen im Wörterbuch, kein Frust.

SCHRITT 2 · DER SYSTEM-PROMPT

Der Blueprint-Prompt für ChatGPT, Claude oder Gemini

Kopiere diesen Prompt in dein bevorzugtes LLM, um strikt satzsynchronisierte Texte im JSON-Format zu generieren: 

Du bist ein erfahrener Computerlinguist und Sprachlehrer.
Erstelle eine satzweise synchronisierte bilinguale Kurzgeschichte zum Sprachenlernen.

SPRACHPAAR: Deutsch (Ausgangssprache) <-> Ukrainisch (Zielsprache)
ZIELNIVEAU (CEFR): A2 - B1
THEMA: [Füge hier dein Wunschthema ein, z. B. 'Eine Fahrradtour durch die Karpaten' oder 'Zubereitung von Borschtsch']
LÄNGE: 10 bis 15 Sätze

REGELN:
1. Striktes 1:1-Satz-Alignment: Jeder deutsche Satz entspricht exakt einem ukrainischen Satz.
2. Keine freien Paraphrasen – der Satzbau soll die Grammatikstrukturen transparent spiegeln.
3. Extrahiere pro Satz 2-3 relevante Kernvokabeln mit Wortart und kurzem Grammatik-Hinweis.
4. Gib das Ergebnis AUSSCHLIESSLICH als valides JSON nach diesem Schema aus:

{
  "title_de": "Titel auf Deutsch",
  "title_uk": "Назва українською",
  "level": "A2-B1",
  "sentences": [
    {
      "id": 1,
      "de": "Deutscher Satz...",
      "uk": "Ukrainischer Satz...",
      "vocab": [
        {"de": "Wort", "uk": "Слово", "pos": "Nomen/Verb", "note": "Erklärung"}
      ]
    }
  ]
}
SCHRITT 3 · AUTOMATION & ANKI-EXPORT

Automatischer Export mit Python (HTML, Markdown & Anki)

Wir haben ein schlüsselfertiges Python-Skript hinterlegt, das deine JSON-Dateien einliest und sofort als druckbares Markdown, interaktiven HTML-Reader oder Anki-Karteikarten-Deck (TSV) exportiert: 

# Python-Generator ausführen:
python scripts/generate_bilingual.py --export-md meine_story.md --export-anki anki_deck.tsv

# Ausgabe:
# [+] Markdown exportiert: meine_story.md
# [+] Anki CSV exportiert: anki_deck.tsv
Skript herunterladen (`generate_bilingual.py`)
SCHRITT 4 · AUDIO & AUSSPRACHE

Text-to-Speech (TTS) mit lebendigen Stimmen

Eine Sprache lernt man nur mit den Ohren. Du kannst die Sätze entweder direkt im Browser über die Web Speech API anhören (wie oben im Reader eingebaut) oder mit der kostenlosen Python-Bibliothek edge-tts kristallklare Audio-Dateien für jeden Satz generieren: 

# Kostenloses Edge-TTS installieren:
pip install edge-tts

# Ukrainischen Satz mit nativer Stimme (z.B. uk-UA-OstapNeural) als MP3 erzeugen:
edge-tts --voice uk-UA-OstapNeural --text "Ясного весняного ранку..." --write-media satz_1_uk.mp3
