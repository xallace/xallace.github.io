Python 3.9+ PyMuPDF (fitz) CLI MIT License

pdf-toc-injector — Heuristic Table-of-Contents Detection & Bookmark Injection

A Python CLI tool for automatically detecting printed tables of contents in multilingual technical monographs (German, English, French, Russian).

  • Locate Table of Contents: Matches heading keywords (Inhalt, Contents, Содержание …) and dot-leader lines with page numbers across the first 35 pages.
  • Compute Page Offset: Locates chapter openings in the body text; the most frequent offset wins (PDF page = printed page + Δ).
  • Hierarchy Recovery: Infers depth from section numbers (1, 1.1, 1.1.1) while clamping multi-level jumps cleanly.
  • Safe Atomic Write: Writes bookmarks to a temporary file first and replaces the original only after page count and bookmark checks pass.
