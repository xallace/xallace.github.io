    From build photos to a rendered tour

    The reference is a public build listing: photos and a parts list of a refurbished 3.5-inch quad. There were no drawings and no CAD data, so every part is a recreation from the photos and the named components.

    1. Reference. RotorBuilds build 37682, “3.5 inch ebay rescue” by chrismaddahl: JM3.5 frame, P1604 motors, DJI O4 Lite, ELRS receiver, M10 GPS and the builder's own TPU parts.
    2. FreeCAD 1.1, by an AI coding agent. An agent generated the base model by script: PartDesign bodies and sketches for the carbon parts, assembly containers per group (chassis, motors and propellers, avionics and power, TPU and hardware) and a build register sheet listing the components and fit checks. Axes: front is −Y, +Z is up.
    3. STEP to Autodesk Fusion. The reference modules went to Fusion as STEP.
    4. My work in Fusion. I checked the model, corrected the lens retaining ring (Fig. 3), set up the motion assembly and rendered the studio image and the build tour.
    FIG. 3 · RETAINING RING AT 25° CAMERA TILT before · after

    Before the fix the ring stayed in place while the camera tilted, so it sat off the lens axis. After the fix it moves with the camera and stays coaxial.
